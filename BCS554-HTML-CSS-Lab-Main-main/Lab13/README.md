Aim:

To build a navigation bar and rows of cards with Flexbox.

Theory:

1. Flexbox lays items out in one direction, a row or a column. It is switched on with display flex on the parent.
2. The main axis is the direction of the row. The cross axis is perpendicular to it.
3. justify-content aligns items along the main axis (for example center or space-between). align-items aligns them along the cross axis.
4. gap sets the space between the items.
5. flex-wrap with the value wrap lets items move to the next line when there is not enough space.

Tasks done:

1. Task 1: A horizontal navigation bar with a gap between links.
2. Task 2: Three cards centred in both directions.
3. Task 3: Stationery shop cards that wrap to the next line.
