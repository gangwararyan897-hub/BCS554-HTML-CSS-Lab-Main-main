Aim:

To link pages together and show an image with proper attributes.

Theory:

1. The anchor tag with an href attribute creates a hyperlink.
2. A relative path such as images/sample.jpg points to a file from the current folder. An absolute path gives the full web address.
3. The img tag shows an image. It needs src (the file path) and alt (a text description). Width and height set the size.
4. Alt text helps screen readers and is shown when the image does not load.
5. Keeping images in a separate images folder keeps the project tidy.
