Aim:

To build forms with text inputs, radio buttons, a dropdown and simple validation.

Theory:

1. The form tag collects user input. The action attribute says where the data is sent and the method is get or post.
2. A label is linked to an input through the for and id attributes. Clicking the label focuses the input.
3. Input types used are text, email and password. Radio buttons with the same name form one group, and only one can be selected.
4. The select tag with option tags makes a dropdown.
5. A button with type submit sends the form.
6. The placeholder attribute shows a hint. The required attribute stops the form from being sent when the field is empty. The email type checks the email format.

Tasks done:

1. Task 1: A sign-up form with full name, email, password and a Sign Up button.
2. Task 2: Radio buttons for gender and a dropdown for course.
3. Task 3: A form with a placeholder and required fields.
