Aim:

To make tables with a caption, head, body and foot, and to make them accessible.

Theory:

1. The table tag holds data in rows (tr), header cells (th) and data cells (td).
2. The caption tag is the title of the table.
3. The thead, tbody and tfoot tags group the header rows, body rows and footer rows.
4. The scope attribute on a th tells screen readers whether the header applies to a column or a row.
5. Class average: Maths is (78 + 64) / 2 = 71 and Science is (85 + 70) / 2 = 77.5.
6. The CSS property border-collapse with the value collapse merges the borders so the table looks clean.

Tasks done:

1. Task 1: A table with caption, head and body for three students.
2. Task 2: A table with a footer row that shows the class average.
3. Task 3: A table that uses the scope attribute on its header cells.
