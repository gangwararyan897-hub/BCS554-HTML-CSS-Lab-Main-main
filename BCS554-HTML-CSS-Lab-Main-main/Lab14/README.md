Aim:

To create grids with columns, an auto-fill gallery and named areas.

Theory:

1. CSS Grid is a two-dimensional layout system, with rows and columns together. It is switched on with display grid.
2. grid-template-columns with the value 1fr 1fr 1fr makes three equal columns. The unit fr means a share of the free space.
3. repeat with auto-fill and minmax(150px, 1fr) makes as many columns of at least 150px as fit, so a gallery adjusts to the screen width.
4. grid-template-areas names regions of the layout and grid-area places an element into a named region.
5. Use Flexbox for one-dimensional layouts and Grid for page layouts and other two-dimensional layouts.

Tasks done:

1. Task 1: Six boxes in three equal columns.
