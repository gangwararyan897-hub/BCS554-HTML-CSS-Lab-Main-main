Aim:

To create unordered, ordered, nested and description lists.

Theory:

1. The ul tag makes an unordered list (bullets). The ol tag makes an ordered list (numbers). Each item uses the li tag.
2. A nested list is a list placed inside an li item of another list. It must be inside the li, not directly inside the ol.
3. The dl tag makes a description list. The dt tag is the term (question) and the dd tag is its description (answer).
4. Lists give a page structure and are read properly by screen readers.
