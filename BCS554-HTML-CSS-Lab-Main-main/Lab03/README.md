Aim:

To write a basic HTML page and use headings, paragraphs, bold text, italic text and line breaks.

Theory:

1. HTML (HyperText Markup Language) describes the structure of a web page using elements made of tags.
2. A basic page has the DOCTYPE line, the html element, a head (title and meta) and a body (what the visitor sees).
3. The title is shown on the browser tab. The meta charset UTF-8 allows all characters.
4. Headings go from h1 (most important) to h6. Use one h1 per page.
5. The p tag makes a paragraph. The strong tag means important text (bold) and the em tag means emphasis (italic).
6. The br tag is a void element. It has no closing tag and just breaks the line.

Tasks done:

1. Task 1: A page with a title and the h1 heading Hello, I am Asha.
2. Task 2: Headings h1, h2 and h3 with a paragraph below them.
3. Task 3: Paragraphs using strong, em and br.
