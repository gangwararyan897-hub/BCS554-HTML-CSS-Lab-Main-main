Aim:

To use the units px, percent and rem, and CSS custom properties (variables).

Theory:

1. px is a fixed pixel size. Percent is relative to the parent element. rem is relative to the root font size (16px by default), so 1.5rem is 24px.
2. CSS variables (custom properties) are defined with two dashes before the name and are usually kept inside :root so the whole page can use them.
3. A variable is used with the var function. Change it once and everything that uses it updates.
4. Design tokens are the central values of a design, such as colours, spacing and font sizes, stored as variables in one file.
