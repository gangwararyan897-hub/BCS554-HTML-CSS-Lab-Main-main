Aim:

To compare box-sizing values, build a card and control overflow.

Theory:

1. Every element is a box made of content, padding, border and margin, from inside to outside.
2. With box-sizing content-box (the default) the width is only the content. In the demo, 200 + 20 + 20 (padding) + 5 + 5 (border) gives a total of 250px.
3. With box-sizing border-box the width includes padding and border, so the box stays 200px.
4. border-radius rounds the corners. A card is a box with padding, border and a background.
5. overflow auto adds a scrollbar only when the content is bigger than the box. Other values are hidden, scroll and visible.

Tasks done:

1. Task 1: Two boxes, one with content-box and one with border-box.
2. Task 2: A card with border, rounded corners and padding.
3. Task 3: A fixed-height box that scrolls when the content is long.
