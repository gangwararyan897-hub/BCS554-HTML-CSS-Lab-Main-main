Aim:

To apply CSS in three ways and to use element, class and id selectors.

Theory:

1. CSS (Cascading Style Sheets) controls how HTML looks.
2. There are three ways to add CSS: inline (the style attribute on a tag), internal (a style tag in the head) and external (a separate css file linked with a link tag). External CSS is best because one file can style many pages.
3. Selectors used are the element selector (h1), the class selector (a dot before the class name) and the id selector (a hash sign before the id name).
4. Specificity: an id beats a class and a class beats an element. An inline style beats all of them. If two rules have equal weight, the later one wins. This is the cascade.
