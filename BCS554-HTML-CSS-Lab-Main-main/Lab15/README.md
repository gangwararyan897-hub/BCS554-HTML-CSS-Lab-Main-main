Aim:

To make pages adapt to phone and desktop widths.

Theory:

1. Responsive design makes one page look good on every screen size.
2. The viewport meta tag with width equal to device-width is required so that phones use their real width.
3. Mobile-first means writing the simple phone layout first and then adding a media query with min-width 600px for bigger screens.
4. A media query applies CSS only when its condition, such as a minimum width, is true.
5. Images are made flexible with max-width 100 percent and height auto.
6. Relative units such as rem, percent and fr scale better than fixed px.

Tasks done:

1. Task 1: Cards stacked on phones and side by side above 600px.
2. Task 2: An image that never overflows its container.
3. Task 3: A heading that becomes larger above 600px.
