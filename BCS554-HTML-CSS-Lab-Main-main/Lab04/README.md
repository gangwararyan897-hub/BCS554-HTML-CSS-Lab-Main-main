Aim:

To group content with div containers, use id, class and data attributes and fix a broken page.

Theory:

1. The div tag is a generic block container. It groups content so it can be styled or positioned.
2. Attributes give extra information to a tag, for example id, class and data attributes.
3. An id must be unique on a page. A class can be reused on many elements.
4. Data attributes store custom data, for example data-topic with the value hobbies.
5. Nesting means putting one element inside another. Tags must close in the reverse order in which they were opened.
6. Browsers forgive many mistakes, but unclosed or wrongly closed tags give unpredictable results. Validators help to find them.

Tasks done:

1. Task 1: Three divs for header, main content and footer.
2. Task 2: A div with an id and a paragraph with a data attribute.
3. Task 3: Fixed a broken page. The h1 was never closed, and a paragraph ended with an opening p tag instead of a closing one.
