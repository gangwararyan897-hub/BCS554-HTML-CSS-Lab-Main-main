Aim:

To build a page with semantic elements, links inside the page and an email link.

Theory:

1. Semantic elements describe their meaning: header (top of the page), nav (navigation links), main (main content), section (a topic block) and footer (bottom).
2. They are better than many plain div tags for accessibility and search engines.
3. A fragment link uses a hash sign before an id in the href. It jumps to the element with that id on the same page.
4. An email link uses mailto in the href and opens the mail application.

Tasks done:

1. Task 1: A header with the name and a nav with two links.
2. Task 2: A main area with an about section.
3. Task 3: A footer with an email link, and a nav link that jumps to the footer.
